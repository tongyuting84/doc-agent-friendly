# 控制台 Agent 操作规范

> 适用于 Agent 根据云控制台操作文档完成资源查询、创建、配置、更新、验证和清理。通用安全、批准和结果规则由[全局 Agent 执行规范](01-global-agent-execution.md)定义。

## 1. 规范边界

本规范只定义控制台特有的文档解析、动态表单、浏览器会话、页面操作、敏感字段和分层验收。产品特有字段、资源依赖和成功状态以当前业务文档和真实控制台为准。

控制台文档只需引用全局规范；全局规范识别到页面、按钮、表单或向导后会加载本规范。

## 2. 标准流程

```text
完整读取控制台文档
→ 提取步骤、字段、依赖和副作用
→ 生成任务专属输入表单
→ 自动发现候选值
→ 一次性收集用户决策
→ 检查登录账号、地域、项目、配额和依赖
→ 输出最终确认单
→ 执行页面操作
→ 查询任务和资源真实终态
→ 分层验收
→ 输出资源台账、告警和清理状态
```

正式执行后，只能因文档外冲突、权限阻塞、库存变化、高风险扩展或不可安全推导的异常中断。

## 3. 动态提取输入

必须逐步识别：

- 用户需要输入、选择或确认的字段；
- 前置资源、权限、登录状态、地域、项目、配额和库存；
- 默认值、示例值、推荐值及其来源；
- 将创建、修改、删除或复用的资源；
- 费用、公网暴露、权限、数据范围和不可逆影响；
- 敏感输入、异步步骤、验收状态及清理依赖。

按全局规范将输入分类。可发现参数优先转换为候选项；无法唯一匹配时让用户选择。不得把示例或页面当前默认选项当作用户真实意图。“最新版本”必须解析为当前实际可选版本并展示具体值。

## 4. 任务专属输入表单

表单只询问无法安全发现或必须由用户决定的内容，并标注必填、条件必填、推荐来源、费用影响、安全影响和敏感字段。关联字段应按选择动态出现。

初始提交按钮使用“检查配置”“生成执行方案”或“继续”，不能直接写“确认创建”。只有完成只读发现后，最终确认单才提供“确认并执行”。

内部参数快照不得包含密码、令牌、AK、SK 或私钥。

## 5. 控制台预检查

有副作用的操作前至少检查：

1. 浏览器已登录的账号是否正确；
2. 地域、项目和目标资源是否匹配；
3. 依赖资源存在且状态可用；
4. 服务授权、权限、配额、库存、余额和费用；
5. 资源名称冲突和重复任务；
6. 公网访问、安全组和权限带来的暴露；
7. 是否具备终态查询和清理能力。

登录态只适用于当前浏览器，不得导出给其他执行渠道。预检查失败时不得提交变更。

## 6. 敏感输入与测试密码

- 不得要求用户在普通聊天中发送密码、AK、SK、私钥或令牌。
- 用户已在页面填写的敏感字段只能检查“已填写”，不得读取、复制或回显。
- 测试资源可在输入表单中提供“自动生成一次性测试密码”，但必须由用户明确选择。
- 自动密码每次随机生成并满足产品规则；不得使用 `admin@1234` 等固定弱密码。
- 自动密码不得出现在聊天、截图、工具日志和报告中。
- 创建前必须确定交付方式：一次性敏感显示、安全凭证存储、权限受限的非仓库临时文件，或用户明确不需要取回。
- 生产、长期运行、共享资源或公网登录节点不得使用测试密码策略。

采用临时文件时，最终回复只提供路径、权限和清理提醒，不显示密码。

## 7. 最终执行确认单

确认必须在所有可发现参数解析和预检查完成后，紧邻第一个有副作用的动作。至少展示：

- 账号、地域、项目和目标环境；
- 创建、修改、删除和复用的资源；
- 名称、数量、规格、版本和计费方式；
- 公网、权限、数据和不可逆影响；
- 已知费用和可能产生但无法精确估算的费用；
- 敏感输入的处理与交付方式；
- 验收条件、最大等待时间和失败处理；
- 清理范围及是否自动清理。

新增收费资源、扩大权限或公网、改变规格数量计费方式、删除已有资源或改变目标环境时必须重新确认。

## 8. 页面执行规则

- 优先使用语义明确的字段、标签、按钮和状态，不依赖易变化的坐标。
- 每完成一步读取页面最新状态，再决定下一步。
- “按钮已点击”“提交成功”或进度条出现都不是业务成功。
- 页面刷新、会话中断或超时后，先按资源 ID、任务 ID 或精确名称查询是否已生效，不得直接重建。
- 页面事实和文档不一致时，以服务端真实状态为准，并记录差异。
- 页面要求的额外高风险字段或资源超出确认范围时停止并重新确认。

## 9. 异步观察和分层验收

分别观察主资源任务、子资源任务、实例或节点就绪、必装组件状态以及文档要求的业务可用性。任务文档提供等待时间时优先采用；否则使用保守观察窗口并记录实际耗时。

必装组件异常会阻塞成功；可选组件异常可以形成 `verified_success_with_warnings`，但必须说明影响。不得仅因进度暂时不动就重复提交。

## 10. 资源台账与最终输出

台账至少包含主资源和子资源的类型、名称、ID、地域、项目、计费方式、自动创建的网络/存储/安全/公网资源、依赖关系、删除保护和清理状态。

最终回复遵守全局规范，并额外说明每层验收结果、持续计费、公网影响、敏感凭证取回位置或处置结果。产品专属示例应放在对应产品文档中，不写入本通用规范。
