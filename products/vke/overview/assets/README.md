# 产品简介图片资源

本目录存放 VKE“产品简介”文档使用的图片。图片按引用文档分目录管理，并使用能够表达内容的英文文件名。

## 使用规则

1. 只迁移用于解释产品架构、流程、对比或场景的有效内容图片，不迁移图标、背景和其他装饰资源。
2. Markdown 使用相对路径引用图片，并提供能够说明图片主题的替代文本。
3. 正文必须补充“图示要点”，确保无法读取图片的 Agent 仍能获得完成任务所需的关键信息。
4. 新增或替换图片时同步更新 [`manifest.yaml`](manifest.yaml)，记录官网来源、来源页面、同步日期和处理方式。
5. 不直接依赖官网 CDN 图片地址，避免外链失效、鉴权或防盗链导致文档图片不可用。
6. 图片中的产品能力和界面可能随版本变化；发现官网图片更新时，应同时检查正文说明是否仍然准确。
