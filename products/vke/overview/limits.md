# 使用限制

使用 VKE 前，应确认账号、余额、配额、库存、网络和依赖云产品满足要求。

## 账号和资源前提

- 创建 VKE 集群前需要完成账号实名认证。
- 创建按量计费资源需要满足账号余额及平台当前的支付条件。
- ECS、EIP、负载均衡等底层资源受配额和库存限制，集群或节点池扩容可能只完成部分资源创建。

## 创建后不可直接变更的配置

集群创建后，部分基础配置不能直接修改，例如集群所属 VPC、容器网络插件和容器网络 CIDR。系统必装组件也不能随意卸载。

## 资源与计费

- 集群依赖的计算、存储、网络和观测资源可能独立计费。
- 删除集群时，部分按量资源可能被级联删除；复用资源、无权限资源或不归集群所有的资源可能保留并继续计费。
- 日志项目、日志主题、存储卷或其他关联资源是否删除，应以具体操作文档和确认页面为准。

## 配额

集群、节点池、节点、路由、服务、存储和 API 调用均可能存在账号级或地域级配额。配额属于动态信息，执行任务前应在配额中心或控制台查询真实值；不要将文档示例值当作当前账号可用额度。

完整限制和申请配额方式请参见[官网使用限制](https://docs.volcengine.com/docs/vke/limits?lang=zh)。
